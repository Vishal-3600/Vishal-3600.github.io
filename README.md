# Vishal Kumar Yadav | Portfolio

Personal portfolio website of **Vishal Kumar Yadav**, a final-year B.Tech Information Technology student (AKGEC, Ghaziabad) focused on Java backend development and applied AI.

**Live site:** https://vishal-3600.github.io

## About the site

A single-page portfolio that presents my projects, internship experience, skills, and education. It is built with plain HTML, CSS, and JavaScript, so there is no build step and nothing to install.

## Features

- Responsive layout that works on phones, tablets, and desktops
- Light and dark themes, with a toggle in the navigation bar
- Interactive `noc-assistant` terminal that demonstrates the network troubleshooting assistant I built at C-DOT (illustrative demo)
- Project cards with a short flow summary, key points, and tech tags
- Sticky navigation with smooth scrolling to each section

## Run locally

```bash
git clone https://github.com/Vishal-3600/Vishal-3600.github.io.git
cd Vishal-3600.github.io
# open index.html in any browser
```

## Deploy

Push `index.html` to the `main` branch of a repository named `<username>.github.io` and enable **Settings → Pages → Deploy from a branch → main / (root)**.
